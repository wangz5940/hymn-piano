# 哈农钢琴练指法 MusicXML 索引

每个 `.musicxml` 文件对应 Audiveris 识别出的一个独立乐章。文件中的 `source-sheet-N` 字段记录其原始 PDF 页码。

## 结构化读取入口

本目录同时提供面向程序和 AI 的结构化数据：

- [`manifest.json`](manifest.json)：数据集、章节和 68 个片段摘要。
- [`segments.jsonl`](segments.jsonl)：每行一个片段，连接 OCR 上下文、MusicXML 哈希、音乐统计和规范化音符事件。
- [`ocr_pages.jsonl`](ocr_pages.jsonl)：按 PDF 页组织的 OCR 文本。
- [`schema.json`](schema.json)：字段契约。
- [`README.md`](README.md)：读取示例、生成命令和质量边界。

`segments.jsonl` 使用 `segment_id` 关联 OCR 页和 MusicXML 文件。当前所有片段状态都是 `needs_review`，不能直接用于正式课程判定。
