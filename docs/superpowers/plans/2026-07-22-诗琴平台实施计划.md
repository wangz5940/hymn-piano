# 诗琴平台实施计划

> **供执行代理使用：** 按任务顺序内联执行，每个任务先写测试、确认失败、再实现并验证。当前目录不是 Git 仓库，因此本计划不执行提交命令；每个任务以测试通过和文件差异核对作为检查点。

**目标：** 建成可直接运行的 48 周诗歌钢琴学习平台，接入 712 个编号、747 张本地歌谱，并提供练习、曲单和记录闭环。

**架构：** React 单页应用使用 HashRouter；构建脚本从歌谱文件名生成只读目录；课程、进度、练习记录和服侍曲单通过版本化仓储保存在 localStorage。候选 MusicXML 不进入首版实时判定。

**技术栈：** React 18、TypeScript、Vite、React Router 6、Lucide React、Vitest、Testing Library、原生 CSS、Web Audio、Web MIDI。

---

- `package.json`：开发、测试、构建和目录生成命令。

## 任务 10：音符级指法、手位与左手和弦教学层

**需求来源：**
- `/Users/bytedance/program/better-panio/doc/documents/指法/指法与手位.md#L680-L741`
- `/Users/bytedance/program/better-panio/doc/documents/指法/指法的原则.md`
- `/Users/bytedance/program/better-panio/doc/documents/指法/十架窄路指法与和弦分析.md`

**目标：** 不再只显示曲目级“手位候选”和“和弦候选”。练习页必须在谱面音符附近显示候选指法圈号，在手位变化处显示颜色区块和移动提示，并在曲目方案中列出左手和弦“哪个手指弹哪个音”。

**设计原则：**
- 指法不是只给一串数字，而是绑定到音符位置。
- 手位是一级教学信息，使用颜色区块表达当前 Position，换位时显示 `Move to ... Position`。
- 左手和弦必须显示音名与手指，例如 `I: E♭-G-B♭ = 5-3-1`、`V7: B♭-D-F-A♭ = 5-3-2-1`。
- OCR 和规则生成的数据均为 `auto_candidate`，人工校对数据为 `ready`，人工数据优先级高于自动候选。
- 所有自动和弦仍标为候选，不把系统推断冒充为谱面原有和弦。

- [x] **步骤 2：生成音符级指法与手位候选**

`generate-hymn-guide-candidates.mjs` 从 OCR block 中筛选简谱数字行，生成紧凑数据：

```ts
interface AutoHymnGuideSeed {
  key_signature: string;
  meter: string;
  tonic_label: string;
  melody_range: string;
  has_accidental: boolean;
  score_marks: ScoreMark[];
  finger_marks: Array<[x: number, y: number, label: string, tone: "base" | "shift"]>;
  position_zones: Array<[y: number, label: string, tone: "base" | "shift"]>;
}
```

指法规则：
- 当前调 1—5：默认 1-2-3-4-5。
- 出现 6、7 或高音 1：切到 `Move to 5 Position`，用 5-6-7-1-2 对应 1-2-3-4-5。
- 黑键和临时升降音优先交给 2、3、4 指。
- 每个标注保留 `base` 或 `shift`，用于绿色/黄色手位区分。

验收：

```bash
npm run generate:guides
rg "finger_marks|position_zones|①|Move to 5 Position" src/data/hymn-guides.generated.ts
```

- [x] **步骤 3：谱面渲染层显示音符指法与手位色带**

`ScoreViewer` 根据 `guide.score_marks` 叠加：

```ts
type ScoreMark =
  | { type: "finger"; label: "①" | "②" | "③" | "④" | "⑤"; x: number; y: number; tone: "base" | "shift" }
  | { type: "position_zone"; label: string; x: number; y: number; width: number; height: number; tone: "base" | "shift" }
  | { type: "key" | "position" | "chord" | "warning"; label: string; x: number; y: number };
```

渲染约定：
- `finger`：显示在音符上方的小圆圈。
- `position_zone`：显示在一行旋律背后的半透明色带。
- `base` 使用绿色，`shift` 使用黄色。
- `key/position/chord` 作为全局提示保留。

- [x] **步骤 4：左手和弦显示“音名 = 手指”**

自动候选按当前调生成：

```text
I   = 1-3-5   = 5-3-1
V7  = 5-7-2-4 = 5-3-2-1
IV  = 4-6-1   = 5-3-1
```

若调号能映射到音名，则渲染为：

```text

V7: B♭-D-F-A♭ = 5-3-2-1
```
